# ADR-003: 秘密情報の保護方式

## ステータス
決定

## コンテキスト
DB接続情報等の秘密情報をエアギャップ環境でどう保護するか検討した。クラウドKMS等は利用不可。

## 決定
RPM/DEBインストール時（`%post`スクリプト）にホスト固有の暗号鍵を生成し、その場でローカル暗号化する。バイナリへの秘密鍵埋め込みは行わない。

## 理由
- エアギャップ環境ではクラウドKMS等の外部鍵管理サービスが使用できない。
- ホスト固有鍵により、バイナリの単純なコピーによる秘密情報漏洩を防ぐ。
