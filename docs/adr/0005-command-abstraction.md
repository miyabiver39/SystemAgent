# ADR-005: コマンド抽象化方式

## ステータス
決定

## コンテキスト
RHEL系・Debian/Ubuntu系の複数バージョン（EOL版含む）を対象とするため、OSコマンドの差分吸収方式を検討した。

## 決定
Capability Providerパターン（ドメイン単位のC#インターフェースは固定、実装差分はOS/バージョンごとのテンプレート(JSON/YAML)として外部化）を採用する。

## 理由
- 多OS・多バージョン・EOL対応をコード変更なしで拡張可能にするため。
- 将来的にAIエージェントがテンプレート追加のみで新OS対応を完結できる構造にするため。
