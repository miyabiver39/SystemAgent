# ADR-009: 監査ログの初期実装範囲

## ステータス
決定（[docs/qa/answers/0001-kickoff.md](../qa/answers/0001-kickoff.md) A3）

## コンテキスト
秘密情報変更操作等の監査ログについて、閲覧UIまで含めるかが基本設計書11章TBD#2として残っていた。

## 決定
初期リリースでは操作ログ（誰が・いつ・何を）をDBに記録するのみとし、閲覧UIは実装しない。閲覧UIは将来対応とする。

## 理由
- 発注者の判断により、初期リリースの優先度は記録機能の確保に置く。
