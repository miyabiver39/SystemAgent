# ADR-012: 証明書失効時の運用（初期リリース）

## ステータス
決定（[docs/qa/answers/0001-kickoff.md](../qa/answers/0001-kickoff.md) A6）

## コンテキスト
エアギャップ環境でのCA失効リスト配布・反映方法が基本設計書11章TBD#5として残っていた。

## 決定
初期リリースでは証明書失効機能（CRL配布等）自体を実装しない。ノードを外す場合は新規CSR発行による再登録のみで対応する。

## 理由
- 発注者の判断により、高度な証明書ライフサイクル管理は専用ツールに委ねるべきであり、初期リリースでは不要と判断された。
