# QA掲示板 運用ルール

AIエージェント(Claude Code等)と人間(発注者)の間の質問・回答をMarkdownファイルでやり取りするための簡易掲示板です。チャットではなくファイルベースでやり取りすることで、決定事項の履歴が`git log`に残り、後から参照できるようにします。

## 構造

```
docs/qa/
├── README.md          ← このファイル（運用ルール）
├── INDEX.md            ← 掲示板の一覧（スレッド一覧・ステータス管理）
├── questions/
│   └── NNNN-slug.md    ← AIエージェントからの質問（AIが作成）
└── answers/
    └── NNNN-slug.md    ← 人間からの回答（発注者が作成・編集）
```

- `questions/` と `answers/` はファイルを分離し、同じ`NNNN-slug`のペアで1スレッドを構成します。
- `NNNN`は4桁の連番（0001, 0002, ...）。`slug`は内容を表す短い英字ID。
- 1スレッド1トピック。複数の論点がある場合は質問ファイル内で見出し(`## Q1`, `## Q2`)を分けます。

## フロー

1. **AIエージェント**が疑問点・未決事項を`questions/NNNN-slug.md`として作成し、`INDEX.md`にステータス「未回答」で追加する。
2. **発注者（あなた）**が`answers/NNNN-slug.md`を作成し、質問ファイルの見出し(`## Q1`等)に対応する形で回答を記入する。
3. 回答ファイルができたら`INDEX.md`のステータスを「回答済み」に更新する（AIエージェントが検知して更新、またはあなたが更新してもよい）。
4. AIエージェントは回答済みスレッドを読み込み、設計書(`docs/design/`)やADR(`docs/adr/`)、実装に反映する。
5. 反映が完了したらステータスを「クローズ」に更新する。

## 質問ファイルのフォーマット例

```markdown
# 0001: タイトル

- ステータス: 未回答
- 起票日: 2026-09-26
- 関連: docs/design/SystemAgent_基本設計書_draft.md 11章 TBD#1

## Q1. 質問タイトル
質問本文。背景・選択肢があれば列挙する。

- 選択肢A: ...
- 選択肢B: ...

## Q2. 質問タイトル
...
```

## 回答ファイルのフォーマット例

```markdown
# 0001: タイトル への回答

- 回答日: 2026-09-27

## A1（Q1への回答）
回答本文。

## A2（Q2への回答）
...
```

## 命名規則
- `slug`はkebab-case、内容が分かる英語（例: `tpm2-support`, `db-schema-naming`）。
- ステータス値: `未回答` / `回答済み` / `クローズ`
