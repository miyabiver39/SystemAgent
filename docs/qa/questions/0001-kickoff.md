## Q1. ソリューション構成（初期スケルトン）について
以下の構成でソリューションを作成しました。この方針で問題ないか、変更したい点があれば教えてください。

```
SystemAgent.sln
src/
  SystemAgent.Core        (共有ドメインモデル・Capability Providerインターフェース)
  SystemAgent.Api         (ASP.NET Core WebAPI。OpenAPI定義が正)
  SystemAgent.Web         (Blazor Server WebUI。APIを呼ぶだけでロジックを持たない)
  SystemAgent.Cli         (CLI。System.CommandLine想定、APIを呼ぶだけ)
tests/
  SystemAgent.Core.Tests
```

- WebUIとAPIは別プロセス（別ポート）を想定していますが、同一ホストプロセス内でBlazor ServerとWebAPIを同居させる構成（1プロセスで完結）でも良いでしょうか？後者の方が配布・サービス管理（systemd unit数）がシンプルになります。
- CLIは将来的にHTTPS+mTLSでAPIを叩く想定ですが、初期スケルトンではlocalhost HTTP直叩きから始めて良いですか？
